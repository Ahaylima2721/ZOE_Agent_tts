Quando é a mesma pergunta?

"Parecido" muda de modelo para modelo. Então a Zoe se calibra no seu computador com 32 pares em português, e os mais difíceis são do mesmo assunto.

Quem escreveu O Fantasma da Ópera?Quem é o autor de O Fantasma da Ópera?MESMA
Como afinar um violão?Como faço para afinar o violão?MESMA
Como instalar o Python no Ubuntu?Como desinstalar o Python no Ubuntu?OUTRA
Quem pintou a Mona Lisa?Onde está exposta a Mona Lisa?OUTRA
Qual a capital da França?Qual a capital da Alemanha?GUARDA
Regra: o limiar fica acima da "outra" mais parecida (+0,02, nunca abaixo de 0,75). Resultado: zero confusões no teste, e ela mostra quantas reformulações reconhece.
calibrate()
worst_neg = max(neg) direct = min(0.99, round( max(worst_neg + 0.02, MIN_DIRECT), 3))
guarda de nomes próprios
def same_entities(a, b): ea, eb = entities(a), entities(b) return not (ea and eb and ea != eb)
por que não um número fixo?

Cada modelo espalha os cossenos de um jeito. A calibração acha a linha entre os dois grupos no modelo instalado. (ilustração)

França × Alemanha: vetores muito próximos, mas nomes diferentes. A guarda impede a resposta trocada, e a pergunta vai para a IA com contexto.
